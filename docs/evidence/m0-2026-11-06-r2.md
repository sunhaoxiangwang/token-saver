## Notes

- The relay manifest for the Claude Code run shows `inbound_outcome: running`: Claude Code stops
  the server with a signal rather than by closing stdin, so the relay's stdin was still open when
  the forwarded signal ended the child. A signal-driven end with no input failure is orderly; any
  framing, read, or forwarding failure would have recorded a different outcome and made the run
  incomplete.
- Codex's `RUST_LOG=info` output contains the account email; the raw log was summarized, hashed,
  and deleted per the evidence policy.
